# Project Instructions for Claude / AI Assistants

## Project Overview
Aya Cosméticos e-commerce and administrative platform built with React, Vite, Tailwind CSS, and Base44 SDK.

## Development Rules
- Maintain clean, modular, and well-commented code.
- Adhere strictly to the established minimalist design tokens and Tailwind utility classes.
- Handle all asynchronous operations and API responses with proper error catching and loading states.
- Do not modify core authentication flows unless explicitly requested.
