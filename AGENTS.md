Guidelines for AI Agents & Developers
This repository contains the codebase for the Aya Cosméticos e-commerce and administrative dashboard.

Code Standards
Use functional React components with hooks.

Follow Tailwind CSS utility classes and the minimalist design system.

Ensure all API calls handle loading and error states gracefully, implementing appropriate try/catch/finally patterns in data-fetching hooks.

Project Structure
src/components/: Reusable UI components and widgets.

src/pages/: Main application routes (Storefront, Admin Dashboard, Auth).

src/lib/: Utility functions, helper modules, and API service integration.
